이 파일 상단(<head> 안 주석)에 Firebase 설정 방법이 적혀 있습니다.

1) Firebase 콘솔에서 프로젝트를 만들고
2) Firestore 규칙을 붙여넣고
3) Authentication에서 이메일/비밀번호로 팀 계정을 하나 만든 뒤
4) 이 HTML 파일 안의 FIREBASE_CONFIG 와 TEAM_EMAIL 값을 채워 넣고 다시 열어주세요.
