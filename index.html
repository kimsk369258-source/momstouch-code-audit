⚙️ 설정이 필요합니다

이 파일 상단(<head> 안 주석)에 Firebase 설정 방법이 적혀 있습니다.

1) Firebase 콘솔에서 프로젝트를 만들고
2) Firestore 규칙을 붙여넣고
3) Authentication에서 이메일/비밀번호로 팀 계정을 하나 만든 뒤
4) 이 HTML 파일 안의 FIREBASE_CONFIG 와 TEAM_EMAIL 값을 채워 넣고 다시 열어주세요.

🔒 팀 비밀번호 로그인

상품코드 대조 대시보드에 접근하려면 팀 공용 비밀번호를 입력하세요.

📋 상품코드 대조 대시보드

일별 매출 데이터를 상품코드 기준표와 자동 대조하고, 이상 유무와 이력을 저장합니다.

🔒 이 사이트의 데이터(기준표, 일별 대조 이력)는 Firebase에 저장되어 팀원 누구나 같은 비밀번호로 로그인하면 이어서 볼 수 있습니다. 로그인 없이는 데이터를 읽거나 쓸 수 없도록 서버 측 규칙으로 막혀 있습니다. 다만 팀 전체가 같은 비밀번호를 공유하는 방식이라 개인별 접근 기록은 남지 않으니, 비밀번호는 필요한 사람에게만 알려주세요.
